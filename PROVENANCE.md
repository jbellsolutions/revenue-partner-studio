# Source provenance

Revenue Partner Studio by Your AI Guy is a clean public source snapshot of the Hermes Orgo Studio implementation, with public-release branding, documentation, a resumable browser installer and an isolated demo. Private Git history, operational evidence, deployment records and old Mac release downloads are excluded.

Hermes Orgo Studio originally imported [orgo-ai-guy-bot](https://github.com/jbellsolutions/orgo-ai-guy-bot) at commit `758d3609d0c7f0a34ea7bdfbd2e7de4d351b9d1a` on September 9, 2026. The preserved runtime is [Hermes Agent](https://github.com/NousResearch/hermes-agent), by Nous Research. Runtime versions and reviewed upstream references remain recorded in `distribution/upstream.json` where available and in the locked dependency files.

GrokBot and the unofficial [reconstruction reference](https://github.com/b-nnett/grok-bot-0.18-reconstructed) informed workflow and layout, not a second runtime or access to proprietary source. The Studio icon in `apps/desktop/assets/studio-icon.*` and `public/studio-icon.png` was newly generated for this project. The public website’s R mark is an original simple vector.

Existing application IDs, Hermes data paths, remote installation paths, service labels and protocol identifiers remain unchanged for upgrade compatibility. Visible names and public links use `brand/product.json`.
