# Support

Start with [troubleshooting](docs/TROUBLESHOOTING.md). For a public issue, include the release version, operating system, affected workflow, exact non-secret error and steps to reproduce using sample data. Redact URLs that identify private workspaces, computer IDs, paths, credentials and conversations. Do not attach raw installer state or provider logs.

Installation assistants should inspect failures and resume the existing installation. This beta has no guaranteed support SLA and is not a managed SaaS subscription.
