# Privacy

The public website has a simulated interactive demo. It contains no sign-in, model request, upload, live terminal or connection to an agent service. Demo choices exist only in page memory and reset on reload. The website does not install analytics or tracking cookies. Cloudflare, as hosting provider, may process ordinary request/network metadata under its own policies.

A private Revenue Partner Studio installation runs in its owner’s Railway and Orgo accounts. The gateway stores computer directory metadata, routing/grants, setup jobs and encrypted connection credentials on its persistent volume. Agents’ conversations, files, memories and provider credentials remain on the selected computer. Explicitly shared task context and artifacts can cross permitted connections.

Model calls go to the provider selected by the owner and are subject to that provider’s policies. Pairing a Mac uses a local companion; access follows owner grants. Imports exclude credentials by default. The publisher does not automatically receive private installation data.

Deleting the browser’s cache does not delete remote work. Use the documented backup and uninstall procedure to retain or remove your own state deliberately.
