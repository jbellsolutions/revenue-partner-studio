# Contributing to Revenue Partner Studio

Read AGENTS.md, then open a focused issue or pull request in this public repository. Describe the user-visible problem, final behavior and checks performed. Use invented fixtures, never real accounts or histories. Preserve the current shell, computer scoping, durable request IDs, profile credential isolation and compatibility paths.

Keep changes small enough to review. Run relevant cloud, desktop, installer or runtime checks, update public documentation and CHANGELOG.md, and report live checks separately from simulated tests. Do not automatically merge Hermes updates; use MAINTENANCE.md. The project is MIT licensed; contributions must retain upstream attribution.
