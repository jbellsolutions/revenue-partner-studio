# Maintenance

This public repository is the continuing feature-development destination. Historical private repositories and older installed clients remain rollback references until migration and acceptance finish. Do not publish private issue bodies, operational evidence or account details during consolidation.

The scheduled upstream workflow checks official Hermes release and development commits and opens review issues here. It does not automatically promote a runtime. Run the compatible provider, handoff, import, permission and screen tests before upgrades. Keep pinned dependencies and runtime provenance current.

CI covers source checks. A maintainer separately reviews real chat/tools, computer switching, screen takeover, restoration, an independent recipient installation and a completed 24-hour reliability trial. Backend sampling is not browser acceptance. Record only sanitized status in docs/RELEASE-CHECKS.md; detailed evidence remains in private owner storage.

Use docs/OPERATIONS.md for deployment, backups, rollback and uninstall. Public site changes deploy independently from private gateways. Never enable a model-funded public demo by adding credentials to the static site.
