# Profiles, providers and imports

Select a computer before changing settings. Studio shows that computer’s actual Hermes profiles, skills, conversations and connection state. Names can repeat across computers; their identities remain distinct. Diagnostic profiles appear under Test agents without erasing their records.

## Providers and models

Use the selected profile’s provider/subscription settings. **Save and check** saves the entered credential for that profile, then validates authentication and model availability; a real tool turn is separate evidence. Supported subscription flows still require provider entitlement. An Anthropic API key, OpenRouter key and ChatGPT/Codex subscription are separate choices. Search available models or enter a provider-supported model ID. Changes apply before the next turn; an unavailable model blocks the turn with an error rather than changing provider billing.

Never include keys in chat. Existing credentials on another computer/profile are not imported automatically. Expired authentication or quota errors remain visible. The installer assistant helps finish supported remote authentication, but cannot manufacture an entitlement.

## Local Hermes and files

Connect a compatible local Mac through the private app’s local pairing download. Native discovery and folder selection are handled by the companion. Local chat and approved folders remain available when the browser reopens. The Mac must be running for its own agent to execute. Cloud agents continue on their own computers when the Mac closes.

Orgo folders use the remote folder browser. Attachments and import bundles support clicking or dropping files. Import destinations are explicit. Mac desktop control remains hidden in this beta.

## Reviewed one-way transfers

Choose source profiles and destination computer, review items, then approve import. Skills, instructions, memory, histories and compatible settings transfer; provider credentials and machine-specific settings do not. Histories are copied as consistent snapshots with provenance. Collisions create separately identified imports; subsequent selected updates use recorded hashes and preserve both versions when source and destination changed. Imported scripts do not execute during transfer.

## Trusted connections and screens

Pairing alone grants no cross-computer action. Create a directional connection for the intended source and destination; review scope and approvals, then revoke when no longer needed. Only explicitly shared artifacts cross boundaries.

Cloud specialists retain their screen assignment while work, viewing or takeover uses it. A fifth occupied screen request queues. **Take control** pauses automation on that screen; **Resume agent** releases it. Separate screens share one operating system and its resources.
